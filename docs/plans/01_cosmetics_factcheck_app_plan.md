# 화장품 팩트체크 웹 앱 초기 구현 계획

이 계획서는 수인님이 원하시는 '화장품 기능성 및 행정처분 검증 앱'을 만들기 위한 첫 번째 스텝입니다. 사용자가 화장품 이름을 검색하면, 식약처 데이터(기능성 인증, 행정처분 이력)를 분석하여 보기 쉬운 리포트 형태로 보여주는 웹 기반 애플리케이션을 구축합니다.

> [!NOTE]
> 초보자인 수인님이 이해하기 쉽도록, 복잡한 기술보다는 가장 기본적이고 직관적인 웹 기술(HTML, CSS, JavaScript)을 사용하여 뼈대를 잡는 것을 목표로 합니다.

## User Review Required

> [!IMPORTANT]
> **식약처 공공데이터 API 연동 안내**
> 실제 식약처 데이터를 실시간으로 가져오기 위해서는 '공공데이터포털'에서 발급받은 API 인증키가 필요합니다. 초기 개발 단계에서는 우리가 방금 전 확인했던 것과 같은 **가상의 데이터(Mock Data)**를 사용하여 앱이 잘 작동하는지 먼저 확인하고, 앱이 완성된 후에 실제 API를 연결하는 방식으로 진행하고자 합니다. 이 방식에 동의하시나요?
