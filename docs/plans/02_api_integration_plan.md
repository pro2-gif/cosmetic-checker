# 식약처 API 실제 연동 구현 계획

이 계획서는 수인님이 발급받으신 식약처 공공데이터 API 인증키(`8438...`)를 앱에 직접 연결하여, 가짜 데이터가 아닌 진짜 식약처 데이터를 실시간으로 가져오는 작업을 위한 설계도입니다.

> [!NOTE]
> 지금은 브라우저(크롬 등)에서 바로 식약처 서버로 요청을 보내는 방식을 시도하겠지만, 브라우저의 강력한 보안(CORS) 때문에 요청이 튕겨나올 수 있습니다. 이를 해결하기 위한 우회 방법도 함께 준비할 예정입니다.

## User Review Required

> [!IMPORTANT]
> **보안 경고(CORS) 우회 동의**
> 인터넷 브라우저에서 곧바로 공공데이터 서버로 데이터를 요청하면 해킹 방지 시스템(CORS)에 막힐 확률이 매우 높습니다. 이를 피하기 위해 임시로 'CORS 우회 프록시(대리인)' 서비스를 사용해서 연결 테스트를 진행하려고 합니다. 이 방법에 동의하시나요?
